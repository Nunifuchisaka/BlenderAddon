# NuniAvatarToolkit

VRChat / VRM アバター制作向けの、メッシュ最適化オールインワンBlenderアドオンです。

- **隠れメッシュ削除** — 服に完全に覆われて外部から見えないボディメッシュの面を自動検出・削除
- **服メッシュフィット** — 頂点グループで指定した範囲のうち、体に埋まっている頂点だけを体表面へ押し出してシェイプキー化
- **貫通チェック** — 服の表面より外側に出ている体メッシュの面を検出し、編集モードで選択してハイライト
- **テクスチャ再リンク** — 欠落しているテクスチャ画像を指定フォルダから検索して自動的に再リンク
- **アーマチュア位置合わせ** — 指定したボーン(既定はHips)のレストポーズ位置が一致するように、別のArmatureを平行移動
- **統合用ボーンウェイト** — アクセサリなどの全頂点を指定ボーンへウェイト1.0で割り当て、メッシュ統合後も追従
- **不要データ一括削除** — 空の頂点グループ・無効なシェイプキー・未使用UVマップ/頂点カラー/マテリアルスロット・浮遊頂点/エッジを削除
- **メッシュ/マテリアル統合** — 複数メッシュの結合(事前チェック付き)、重複マテリアルスロットの統合
- **統計/書き出し前チェック** — ポリゴン数などのPC/Quest別の参考ランク表示と、書き出し前の不整合チェック

## 対応バージョン

Blender 4.2 以降。Linux版 Blender 4.2.0・4.3.2・5.2.0で自動テストを実施しています。レガシー形式(`bl_info`)のアドオンとして配布しています。検証範囲と修正内容は[リリース前の作業報告](docs/reviews/2026-10-13-release-safety-fixes.md)を参照してください。

## インストール

1. 配布ZIP(`NuniAvatarToolkit-1.0.1.zip`)を展開せずに用意します。
2. Blenderの `編集 > プリファレンス > アドオン` を開き、右上の`∨`メニューから`ディスクからインストール`を選んで配布ZIPを指定します。
3. 一覧に表示された「NuniAvatarToolkit」にチェックを入れて有効化します。
4. 3Dビューポートのサイドバー(`N`キー)に「Avatar Toolkit」タブが追加されます。

更新時はアドオンを無効化してから、新しいZIPを同じ手順でインストールし、有効化してください。1.0.1では更新時に機能モジュールも読み直します。

## 各機能の使い方

### 1. 隠れメッシュ削除

体メッシュの各頂点から放射状にレイを飛ばし、服(または任意で体自身)に完全に囲まれて外部から絶対に見えない頂点・面を自動検出します。

1. 「ボディメッシュ」に体オブジェクトを指定します。
2. 「服メッシュ」一覧の「＋」で欄を追加し、体を覆っている服オブジェクトをひとつずつ指定します。
3. 必要であれば「サンプル数」「オフセット比率」「判定モード」「安全余白」を調整します。「安全余白」は削除候補を境界から1～3段階内側へ縮め、アバターが動いたときに穴が露出しにくくします(通常は「中」を推奨)。
4. 表情シェイプキーで見える可能性がある口の中・目の周りなどを保護したい場合は、対象の頂点グループを作成し「除外頂点グループ」で指定してください。
5. 「隠れた面を選択」を実行します。自動的に編集モードに入り、隠れていると判定された面がハイライトされます。**この時点では何も削除されません。** 目視で確認し、必要であれば手動で選択を調整してください。
6. 問題なければ「選択した面を削除」を実行します(確認ダイアログが表示されます)。削除直前のボディは、非表示の独立コピーとして`AMT_Backups`コレクションへ自動保存されます。

**重要な注意点:**
- シェイプキー(まばたき・視線・口の開閉など)や、ゲーム内で切り替える別の服を装着したときにだけ見える面が誤って削除されないよう、削除前に必ず目視確認してください。「自身のメッシュも遮蔽物に含める」を有効にする場合は特に注意が必要です(口の中などが削除対象になりやすくなります)。
- Subdivision Surface・Mirror・Booleanなど、頂点数を変えるモディファイアが体メッシュに設定されている場合、これらのモディファイアを一時的に無効化した状態でポーズを評価します。それでも頂点数が一致しない場合は、変形前(レスト位置)の座標で判定される旨が警告表示されます。
- 処理はモーダル(ESCでキャンセル可能)で実行され、進行状況がステータスバーに表示されます。頂点数×サンプル数が多いアバターでは時間がかかることがあります。
- 除外されたコレクションやモニター非表示のメッシュは判定対象にできません。対象を現在のビューレイヤーで有効にしてください。共有・リンクされたボディの選択／削除は行わず、解析のみを許可します。
- 「いずれかの頂点」の判定でも、除外頂点グループを含む面は削除候補から外します。

#### Python API／AIエージェントからの操作

Blender内でPythonを実行できるAIエージェントやスクリプトからは、公開関数`NuniAvatarToolkit.run_hidden_mesh`を使用できます。オブジェクト名またはBlenderオブジェクトを渡せます。

```python
import NuniAvatarToolkit

result = NuniAvatarToolkit.run_hidden_mesh(
  body="Body",
  clothing=["Tops", "Jacket"],
  action="SELECT",  # ANALYZE / SELECT / DELETE
  safety_margin="MEDIUM",  # NONE / SMALL / MEDIUM / LARGE
)
print(result)
```

`ANALYZE`は変更を加えず結果だけを返し、`SELECT`は安全余白適用後の面を選択します。`DELETE`は同じ面を削除しますが、必ず先に`AMT_Backups`コレクションへボディの独立コピーを作成します。戻り値は面番号や件数、バックアップ名を含むJSON化可能な辞書です。

### 2. 不要データ一括削除

1. 「対象メッシュ」に処理したいオブジェクトを指定します。
2. 削除したい項目にチェックを入れます(デフォルトで全項目が有効です)。
3. 「スキャン」で削除候補件数を確認します(削除は行いません)。
4. 内容を確認し、「削除を実行」を実行します(確認ダイアログが表示されます)。

モディファイアやシェイプキーから参照されている頂点グループ、実際に割り当てられたマテリアルのノードが参照するUVマップ/頂点カラー、ドライバー制御に使うシェイプキーは保護します。編集モードの変更を同期してから削除候補を判定します。

共有・リンク・ライブラリオーバーライドのMeshは、変更前に処理を中止します。Solidify・Bevel・Wireframe・Geometry Nodesなど素材番号の維持を確認できないモディファイアが残っている場合、未使用素材スロットの削除も中止します。先に複製したメッシュへモディファイアを適用するか、「未使用のマテリアルスロット」をオフにして他の項目だけを処理してください。

### 3. メッシュ/マテリアル統合

- **選択メッシュを結合**: 結合先にしたいオブジェクトをアクティブにした状態で、結合したい全てのメッシュを選択してから実行します。シェイプキーの有無やアーマチュア/UV構成の違いなど、結合前に注意すべき点があれば確認ダイアログに表示されます(Blender標準の結合機能では、アクティブオブジェクト以外のシェイプキーは失われる点にご注意ください)。
- **重複マテリアルスロットを統合**: アクティブオブジェクトの中で同一マテリアルを参照している重複スロットを1つにまとめ、重複していたスロットだけを削除します(確認ダイアログが表示されます)。重複と関係のない未使用スロットは残ります。メッシュを他のオブジェクトと共有している場合や、リンクされている場合は処理しません。

Solidify・Bevel・Wireframe・Geometry Nodesなど素材番号に依存するモディファイアが残っている場合、重複スロット統合は中止します。表示を無効にしているモディファイアも対象です。先に複製したメッシュへ適用してから統合してください。結合先が共有Meshの場合も、未選択のオブジェクトを保護するため結合を中止します。

### 4. 統計/書き出し前チェック

1. 体・服・アーマチュアなど、アバター一式をまとめたコレクションを作成し、「アバターコレクション」に指定します。
2. 「診断を実行」を実行すると、以下が一覧表示されます。
   - 評価後のポリゴン数・マテリアルスロット数、ボーン数・シェイプキー数と、PC/Quest別の参考ランク(Excellent〜Very Poor。例: 【PC: Excellent / Quest: Good】)
   - 不正な座標(NaN/Inf)を含む頂点の有無(Basisを含むすべてのシェイプキー内の座標も検査)
   - メッシュとArmatureのスケールのマイナス値・不均一スケール・回転未適用の警告(デルタトランスフォームも含む)
   - 非多様体(ノンマニフォールド)エッジ数
   - どのメッシュからもウェイトが乗っていないボーンの一覧(**削除は行いません**。PhysBoneなど、メッシュのウェイト情報だけでは判断できない参照が他にある可能性があるため、確認は必ず手動で行ってください)
   - サブコレクションを使わずコレクション直下に直接置かれたメッシュ(サブコレクションが1つ以上ある場合のみチェックします)
   - 除外(Exclude)または非表示(hide_render)のコレクションに中身が入っている状態(指定コレクション自身・祖先も検査。入れ子の場合は最上位のみ報告します)
   - 複数のコレクションへ重複して所属しているオブジェクト
   - アーマチュアオブジェクトが0個、または2個以上ある状態
   - コレクション名が初期値(`Collection`、`Collection.001`など)のままのもの
   - 中身が空のサブコレクション

> **コレクション構成のチェックについて**: 分類名(衣装/Accessoryなど)は問いません。サブコレクションを一切使わないフラットな構成では、構成に関する警告は出ません。

> **参考ランクについて**: ポリゴン数・マテリアルスロット数・ボーン数のランク表示は、VRChatのAvatar Performance Ranking SystemのPC版とQuest(Mobile)版の基準を参考にした概算値です。マテリアルスロット数は、同じマテリアルを複数のスロットで使っている場合もスロットごとに数えます。アバターコレクションは現在のシーンにあるものを指定してください。VRChat側の基準は将来変更される可能性があるため、最終判断の際は必ずVRChat公式ドキュメントで最新の基準をご確認ください。

### 5. テクスチャ再リンク

BOOTHで購入したアバターのFBX/Blendファイルを読み込んだ際、テクスチャ画像が見つからない(ビューポート上で紫/ピンク表示や欠落アイコンになる)ことがあります。この機能は、その欠落しているテクスチャ画像を、指定したフォルダから探して自動的に再リンクします。

1. 「検索フォルダ」に、テクスチャファイルが入っているフォルダを指定します(サブフォルダも再帰的に検索します)。
2. 「欠落テクスチャを再リンク」を実行します。
3. 結果が下部にレポート表示されます。画像ごとに「再リンクしました」「候補が複数あるためスキップしました」「見つかりませんでした」などが表示されます。リンクされた(別の.blendから読み込んだ)画像は変更せず、その旨を表示します。

**マッチングの仕組み(優先順位順):**
1. 画像名とファイル名が完全に一致するもの。
2. 拡張子の違い・大文字小文字の違い・Blenderが付与する重複サフィックス(`.001`等)の違いを許容して名前が一致するもの。
3. 名前の一部が一致するもの(部分一致)。
4. 同じ一致レベルで候補が複数見つかった場合は、誤ったファイルを自動選択しないよう再リンクせず、レポートに候補を列挙します。手動で個別に対応してください。

**重要な注意点:**
- あくまでフォルダ内に実在するファイルとの再リンクのみを行います。テクスチャファイル自体が手元に存在しない場合はこの機能では解決できません。
- FBXインポート時にテクスチャノード自体が作成されなかった場合(画像データブロックがそもそも存在しない場合)は対象外です。
- 候補が実際に画像として読み込めることを確認してからパスを変更します。壊れたファイルは成功とせず、元パスを維持して再試行可能にします。UDIM・連番・動画・パック済み画像はこの再リンクの対象外です。

### 6. アーマチュア位置合わせ

同一アバターの別バージョン(例: 素足版とハイヒール版)のArmatureを重ねて比較したいとき、オブジェクトの`location`が両方`(0, 0, 0)`でも、実際のボーン配置(レストポーズ)がズレていることがあります。この機能は、指定したボーン(既定はHips)のレストポーズ・ワールド座標が一致するように、対象Armatureオブジェクト全体を平行移動します。

1. 「基準Armature」に、動かさずに基準としたいArmatureを指定します。ボーンは自動的に"Hips"相当のものが選択されますが、UIから選び直せます。
2. 「対象Armature」に、位置を合わせて動かしたいArmatureを指定します。
3. 「位置を合わせる」を実行すると、対象Armatureが平行移動し、指定ボーンの位置が基準側と一致します。

**重要な注意点:**
- 位置(平行移動)のみを一致させます。回転・スケールは変更しません。
- レストポーズ(Edit Modeでのボーン配置)を基準にします。現在のポーズ(Pose Mode)は見ません。
- 対象Armatureに親付けされたメッシュは一緒に移動しますが、Armatureモディファイアだけで紐づいていて親付けされていないメッシュは移動しません(その場合はレポートに警告が表示されます)。
- Armature編集中は実行せず、オブジェクトモードへの切替を案内します。コンストレイント・ドライバーなどで位置だけを安全に合わせられない場合は、変更したチャンネルを元に戻します。

### 7. 統合用ボーンウェイト

アクセサリなどのメッシュをアバター本体へ統合する前に、全頂点を指定したArmatureのひとつのボーンへウェイト1.0で割り当てます。結合後も、UnityやVRChatで指定ボーンに剛体的に追従させるための機能です。

1. 「対象メッシュ」に統合したいアクセサリなどのメッシュを指定します。
2. 「Armature」に追従先のArmatureを指定します。
3. 「ボーン」から追従先のボーンを選択します。
4. 「統合用ウェイトを設定」を実行します。
5. 対象メッシュと、同じArmatureモディファイアを設定した結合先メッシュを選択し、結合先をアクティブにして「選択メッシュを結合」を実行します。

既存の同じArmatureに属するボーンウェイトは対象メッシュから外し、指定ボーンだけへウェイト1.0を設定します。Armatureモディファイアがなければ自動追加します。結合先と別のArmatureモディファイアを持つメッシュ、Bone Parentが設定済みのメッシュ、リンクされていて変更できないメッシュは安全のため処理しません。

共有Mesh・Meshデータだけがリンクされている対象・非変形ボーン(`use_deform=False`)も、既存ウェイトを外す前に拒否します。共有対象は先にシングルユーザー化し、追従先には変形に使うボーンを選んでください。

### 8. 服メッシュフィット

他のアバター向けに作られた服を着せると、体の一部が服を突き抜けて肌がはみ出すことがあります。この機能は、服メッシュのうち頂点グループで指定した範囲だけを対象に、体メッシュへ埋まってしまっている頂点を体表面まで押し出し、その結果をシェイプキーとして追加します。全体をShrinkwrapで吸着させるのと違い、直したい部分(胸まわり・腰まわりなど)だけを狙って修正できます。

1. あらかじめ服メッシュに、フィットさせたい範囲の頂点グループを作成します。ウェイト値がそのままフィットの強さになるため、範囲の境界を0へ向けてぼかしておくと段差が出ません。
2. 「ボディメッシュ」に体のメッシュを、「服メッシュ」に変形させたい服のメッシュを指定します。
3. 「対象頂点グループ」で、手順1で作成した頂点グループを選択します。
4. 必要に応じて「オフセット」(体表面から浮かせる距離)と「最大探索距離」を調整します。
5. 「フィットしてシェイプキーを作成」を実行すると、服メッシュにシェイプキー(既定名は`AMT_Fit`)が値1.0で追加されます。

体の外側にある頂点は動かさず、内側に埋まっている頂点だけを押し出すため、服のシルエットは保たれます。押し出し先は体表面の最近傍点で、そこから法線方向へ「オフセット」の分だけ浮かせた位置です。

**重要な注意点:**
- 結果はシェイプキーなので、値を0にすればいつでも元の形状に戻せます。効き具合をスライダーで弱めることもできます。
- 同じ名前のシェイプキーが既にある場合は、確認ダイアログのうえで上書きします。部位ごとに別のシェイプキーを作りたい場合は「シェイプキー名」を変えて実行してください。
- 計算中はArmatureを一時的にレストポーズとして扱います(シェイプキーはモディファイア適用前の座標に効くため)。実行後、ポーズは元に戻ります。
- 「最大探索距離」より遠い頂点は処理されません。大きく離れた位置にある服を合わせたい場合は、この値を大きくするか0(距離制限なし)にしてください。
- 変更する服はローカルかつシングルユーザーのMeshにしてください。absoluteキー、自己参照する相対キー、ミュート済みキー、値1.0を含まないスライダー範囲の既存キーは、設定を自動変更せず実行を中止します。
- 服側の有効なArmatureとデータ専用モディファイアには対応します。Displace・Shrinkwrap・Mirror・Subdivisionなど、座標や頂点構成を変える服側モディファイアは無効化して確認するか、複製した服へ適用してから実行してください。

### 9. 貫通チェック

他アバター向けの服を着せると、体の一部が服を突き抜けて肌がはみ出す(貫通)ことがあります。この機能は、服の表面より外側に出ているボディメッシュの面を検出し、編集モードで選択してハイライトします。**検査のみを行い、削除や変形は一切行いません。**

1. 「ボディメッシュ」に体オブジェクトを指定します。
2. 「服メッシュ」一覧の「＋」で欄を追加し、体を覆っている服オブジェクトをひとつずつ指定します。
3. 必要であれば「最大探索距離」「検出しきい値」「判定モード」を調整します。
4. 顔・手・足など、そもそも服から出ているのが正しい部位を保護したい場合は、対象の頂点グループを作成し「除外頂点グループ」で指定してください。
5. 「貫通をチェック」を実行します。貫通していると判定された面が編集モードで選択され、面数と最大突き出し量がレポートに表示されます。

**判定の仕組み:** 体の各頂点から最も近い服の表面を探し、その点より外側に出ているかどうかで判定します。「最大探索距離」より近くに服が無い頂点は、そもそも服に覆われていない部分(手・頭・足など)として判定から除外されます。したがって、襟ぐりや袖口の肌が誤検出される場合は「最大探索距離」を小さくしてください。逆に、厚みのある服の貫通が検出されない場合は大きくします。

**重要な注意点:**
- 判定は**現在のポーズ**で行います。貫通はポーズによって出たり消えたりするため、問題が起きているポーズを取らせた状態で実行してください(シェイプキーを作る「服メッシュフィット」がレストポーズで計算するのとは逆です)。
- 「検出しきい値」は、面同士がぴったり接している状態を貫通と誤検出しないための余裕です。ノイズのように細かい面が大量に選択される場合は大きくしてください。
- 見つかった箇所は、「服メッシュフィット」で服を膨らませるか、「隠れメッシュ削除」で体側の面を削って対処します。
- 面選択を共有する別オブジェクトを保護するため、共有Meshのボディは拒否します。参照する服のMesh共有は可能です。

## 全般的な注意事項

- 削除系の操作を実行する前には、必ずファイルを保存するか複製を作成してください。
- 本アドオンの削除操作はBlenderの元に戻す(Ctrl+Z)の対象です。ファイルを開き直したりBlenderを終了した後は、そのUndo履歴を利用できません。
- 「隠れメッシュ削除」「不要データ一括削除」は、シェイプキーや服の着せ替えなど、実行時点では見えていないが将来的に見える可能性のある面・データを削除してしまう可能性があります。用途に応じて除外設定を活用し、必ず目視確認のうえ削除してください。
