# Avatar Mesh Toolkit (アバターメッシュツールキット)

VRChat / VRM アバター制作向けの、メッシュ最適化オールインワンBlenderアドオンです。

- **隠れメッシュ削除** — 服に完全に覆われて外部から見えないボディメッシュの面を自動検出・削除
- **不要データ一括削除** — 空の頂点グループ・無効なシェイプキー・未使用UVマップ/頂点カラー/マテリアルスロット・浮遊頂点/エッジを削除
- **メッシュ/マテリアル統合** — 複数メッシュの結合(事前チェック付き)、重複マテリアルスロットの統合
- **統計/書き出し前チェック** — ポリゴン数などの概算ランク表示と、書き出し前の不整合チェック

## 対応バージョン

Blender 3.6 以降(4.x系含む)。レガシー形式(`bl_info`)のアドオンとして配布しています。

## インストール

1. `avatar_mesh_toolkit` フォルダをZIP圧縮します。
2. Blenderの `編集 > プリファレンス > アドオン > インストール` から、作成したZIPファイルを選択します。
3. 一覧に表示された「Avatar Mesh Toolkit」にチェックを入れて有効化します。
4. 3Dビューポートのサイドバー(`N`キー)に「Avatar Toolkit」タブが追加されます。

## 各機能の使い方

### 1. 隠れメッシュ削除

体メッシュの各頂点から放射状にレイを飛ばし、服(または任意で体自身)に完全に囲まれて外部から絶対に見えない頂点・面を自動検出します。

1. 「ボディメッシュ」に体オブジェクトを指定します。
2. 服オブジェクトをまとめた新規コレクションを作成し、「服コレクション」に指定します。
3. 必要であれば「サンプル数」「オフセット比率」「判定モード」を調整します(通常はデフォルトのままで問題ありません)。
4. 表情シェイプキーで見える可能性がある口の中・目の周りなどを保護したい場合は、対象の頂点グループを作成し「除外頂点グループ」で指定してください。
5. 「隠れた面を選択」を実行します。自動的に編集モードに入り、隠れていると判定された面がハイライトされます。**この時点では何も削除されません。** 目視で確認し、必要であれば手動で選択を調整してください。
6. 問題なければ「選択した面を削除」を実行します(確認ダイアログが表示されます)。

**重要な注意点:**
- シェイプキー(まばたき・視線・口の開閉など)や、ゲーム内で切り替える別の服を装着したときにだけ見える面が誤って削除されないよう、削除前に必ず目視確認してください。「自身のメッシュも遮蔽物に含める」を有効にする場合は特に注意が必要です(口の中などが削除対象になりやすくなります)。
- Subdivision Surface・Mirror・Booleanなど、頂点数を変えるモディファイアが体メッシュに設定されている場合、これらのモディファイアを一時的に無効化した状態でポーズを評価します。それでも頂点数が一致しない場合は、変形前(レスト位置)の座標で判定される旨が警告表示されます。
- 処理はモーダル(ESCでキャンセル可能)で実行され、進行状況がステータスバーに表示されます。頂点数×サンプル数が多いアバターでは時間がかかることがあります。

### 2. 不要データ一括削除

1. 「対象メッシュ」に処理したいオブジェクトを指定します。
2. 削除したい項目にチェックを入れます(デフォルトで全項目が有効です)。
3. 「スキャン」で削除候補件数を確認します(削除は行いません)。
4. 内容を確認し、「削除を実行」を実行します(確認ダイアログが表示されます)。

モディファイアやシェイプキーから参照されている頂点グループ、マテリアルノードから参照されているUVマップ/頂点カラーは、たとえ一見未使用に見えても保護され、削除対象になりません。

### 3. メッシュ/マテリアル統合

- **選択メッシュを結合**: 結合先にしたいオブジェクトをアクティブにした状態で、結合したい全てのメッシュを選択してから実行します。シェイプキーの有無やアーマチュア/UV構成の違いなど、結合前に注意すべき点があれば確認ダイアログに表示されます(Blender標準の結合機能では、アクティブオブジェクト以外のシェイプキーは失われる点にご注意ください)。
- **重複マテリアルスロットを統合**: アクティブオブジェクトの中で同一マテリアルを参照している重複スロットを1つにまとめ、不要になったスロットを削除します。

### 4. 統計/書き出し前チェック

1. 体・服・アーマチュアなど、アバター一式をまとめたコレクションを作成し、「アバターコレクション」に指定します。
2. 「診断を実行」を実行すると、以下が一覧表示されます。
   - ポリゴン数・マテリアル数・ボーン数・シェイプキー数と、参考ランク(Excellent〜Very Poor)
   - 不正な座標(NaN/Inf)を含む頂点の有無
   - スケールのマイナス値・不均一スケール・回転未適用の警告
   - 非多様体(ノンマニフォールド)エッジ数
   - どのメッシュからもウェイトが乗っていないボーンの一覧(**削除は行いません**。PhysBoneなど、メッシュのウェイト情報だけでは判断できない参照が他にある可能性があるため、確認は必ず手動で行ってください)

> **参考ランクについて**: ポリゴン数・マテリアル数・ボーン数のランク表示は、VRChatのAvatar Performance Ranking Systemを参考にした概算値です。VRChat側の基準は将来変更される可能性があるため、最終判断の際は必ずVRChat公式ドキュメントで最新の基準をご確認ください。

## 全般的な注意事項

- 削除系の操作を実行する前には、必ずファイルを保存するか複製を作成してください。
- 本アドオンの削除操作はBlenderの通常の元に戻す(Ctrl+Z)機能に対応していますが、ファイルを保存した後は元に戻せません。
- 「隠れメッシュ削除」「不要データ一括削除」は、シェイプキーや服の着せ替えなど、実行時点では見えていないが将来的に見える可能性のある面・データを削除してしまう可能性があります。用途に応じて除外設定を活用し、必ず目視確認のうえ削除してください。
